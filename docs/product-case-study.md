# 产品案例：从教练备课到机构训练资产

## 用户与首期范围

项目面向青训机构和中小足球俱乐部。一线教练要在目标、球员人数、年龄和场地变化时准备或修改训练方案；技术主管和机构管理者关心的是同一球队的计划能否延续，以及教案能否留在机构内供团队复用。这些是从公开教练资料和备课任务出发形成的产品假设，尚待客户验证。

首期先做一堂完整训练课的制定、修改和保存。单项练习、多周计划、多人实时协作与复杂审批留在后续范围。机构价值围绕「球队建档 → 训练周期 → 备课与调整 → 现场记录 → 方案复用」展开。

## 三个产品决定

| 决定 | 用户会看到什么 |
| --- | --- |
| 个人身份与机构空间分开 | 教练可管理自己的球队，也可按分配进入机构球队。机构方案随机构空间留存，成员离开后不再有访问权；这是权限与数据归属设计。 |
| 单次需求优先于球队默认值 | 例如球队常规 60 分钟，本次临时改为 45 分钟，只修改当前方案；不会改写球队长期设置。 |
| 修改和恢复都保留历史 | 新版与旧版各自保留创建时的球队和周期背景，恢复旧版会另建一个版本。单次训练反馈是一次观察；要形成长期认识，需要单独确认。 |

## 交付与验证

- 设计了产品架构、角色和数据对象关系、核心 Agent 工作流，以及案例入库和来源规则。
- 发布六页响应式 Demo，用虚构球队展示备课、调整、回看、反馈和机构视角。既有浏览器验收覆盖 60→45 分钟调整、历史恢复、下载、反馈保存和窄屏布局。
- 独立本地 Agent 原型做过真实模型联调；机构角色、长期反馈和方案复用仍分别处于设计或演示阶段。后续应验证方案采纳、现场修改频率、备课耗时和机构复用意愿。
