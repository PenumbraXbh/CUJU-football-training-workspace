# Demo 开发说明

这是在线作品的静态源码。页面使用虚构数据和预设教案，无需 API Key、模型服务或数据库。教练与主管视图用于演示界面差异。

## 本地运行

需要 Node.js，无第三方依赖。在仓库根目录分两行执行：

```sh
cd demo
npm start
```

浏览器打开 `http://127.0.0.1:4318` 即可。

## 检查与部署

在 `demo/` 目录运行 `npm run check`，可检查预设时长、版本快照、历史恢复、导出提示及静态边界。此检查不调用模型，也不评估教案的专业质量。

如需自行托管，将 `demo/dist/` 作为静态网站根目录。
