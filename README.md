# 足球青训教练工作台

**B 端 AI 产品 0→1 实践** · 个人项目

[在线体验六页 Demo](https://cuju-coach-workspace-demo.nilus.chatgpt.site/) · [产品案例](docs/product-case-study.md) · [Agent 与评测](docs/agent-and-evaluation.md)

面向青训机构和中小足球俱乐部。教练根据球员年龄、人数、训练目标和场地条件制定或调整训练课；机构可围绕球队与训练周期规划教案归档、反馈记录及方案复用。首期聚焦完整训练课的制定和修改。

## 两分钟体验

1. 打开在线 Demo，进入「训练设计」，选择「体验示例生成」。
2. 将 60 分钟示例调整为 45 分钟，查看版本历史，再恢复旧版并导出演示文本。
3. 打开「训练反馈」记录一次观察；在「机构协作」切换教练和主管视图。

Demo 使用虚构球队和预设方案，角色切换展示界面差异。它是独立的静态原型，无需 API Key，不调用模型服务，也不实现账号鉴权。完整课次以外的训练类型仅作结构展示。
